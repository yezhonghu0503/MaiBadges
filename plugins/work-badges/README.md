# MaiBadges 本地管理插件

插件 slug 为 `work-badges`，提供 `work_badges_open` 管理页和本地角色工具。新增、编辑、复制、停用工牌，上传头像，保存用户确认的完整聊天标题绑定；资料保存在本机 SQLite 与头像目录。

管理插件本身不连接桌面调试端口、不启动浮动加载器。可选加载器属于完整源码包，需用户按 [根目录安装流程](../../INSTALL.md) 明确登记和启用。它不是官方原生侧栏插槽。
