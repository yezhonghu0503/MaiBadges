# MaiBadges 0.8.0 本地管理插件

插件 slug 为 `work-badges`，提供 `work_badges_open` 管理页和本地角色工具。新增、编辑、复制、停用工牌，上传头像，保存用户确认的完整聊天标题绑定；资料保存在本机 SQLite 与头像目录。

管理插件本身不连接桌面调试端口、不启动桌面加载器。可选加载器属于完整源码包，需用户按 [根目录安装流程](../../INSTALL.md) 明确登记和启用。0.7.0 公开包只有右侧浮动工牌；0.8.0 补入左侧员工卡片，仅装饰已确认绑定、可识别且无歧义的导航行，保留点击和定时任务图标。它不是官方原生侧栏插槽，不保证所有宿主版本兼容。

从 0.7.0 升级时需更新完整源码或安装包、运行 `prepare`、通过宿主正常功能更新插件并重启加载器。保留原 state 目录即可保留角色、头像和绑定；`install-launcher` 只更新入口。详见 [升级说明](../../UPGRADE.md)。
