# 安装

请从完整源码包根目录按 [INSTALL.md](../../INSTALL.md) 操作。插件文件夹本身不包含完整准备与入口工具。

本地来源默认 `maibadges-local`，插件名 `work-badges`，管理工具 `work_badges_open`。使用宿主的正常本地插件安装功能，不手改插件缓存。用户资料默认在 `~/Library/Application Support/MaiBadges`。

管理插件可独立使用。可选浮动工牌需要用户显式选择主窗口、保存聊天绑定并启动加载器；仅安装插件不会连接 CDP 或设置登录自启。完整权限与停用步骤均在根目录安装文档中。
