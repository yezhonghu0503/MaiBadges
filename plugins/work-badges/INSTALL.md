# 安装 MaiBadges 0.8.0

请从完整源码包根目录按 [INSTALL.md](../../INSTALL.md) 操作。插件文件夹本身不包含完整准备与入口工具。

本地来源默认 `maibadges-local`，插件名 `work-badges`，管理工具 `work_badges_open`。使用宿主的正常本地插件安装功能，不手改插件缓存。用户资料默认在 `~/Library/Application Support/MaiBadges`。

管理插件可独立使用。右侧浮动工牌与左侧员工卡片需要用户显式选择主窗口、保存聊天绑定并启动可选加载器；仅安装插件不会连接 CDP 或设置登录自启。左侧仅装饰已确认绑定、可识别且无歧义的导航行，保留点击和定时任务图标；不保证所有宿主版本兼容。完整权限与停用步骤均在根目录安装文档中。

0.7.0 公开包不含左侧员工卡片。已有用户按 [升级说明](../../UPGRADE.md) 一并更新完整源码或安装包，运行 `prepare`、通过宿主正常功能更新插件并重启加载器，沿用原 state 目录保留头像和绑定。`install-launcher` 仅刷新入口。
