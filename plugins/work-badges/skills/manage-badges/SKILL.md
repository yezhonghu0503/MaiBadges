name: manage-badges
description: 在 MaiBadges 中新增、编辑、复制、停用多角色工牌，上传头像，查看或修改用户确认的聊天绑定。
---

需要管理工牌时，调用本插件 MCP 工具 `work_badges_open` 打开管理页。管理页是资料与绑定的主要编辑入口；用户可在页内新增、编辑和保存，无需改源码。

真实资料源为本地 SQLite 与头像目录，不依赖模型记忆。读取用 `work_badges_snapshot`；修改前读取最新 `expectedVersion`，冲突后重新读取，禁止盲目覆盖。头像由管理页上传；`work_badges_avatar` 的图片内容通过工具 `_meta` 供界面使用，不要复制大段图片编码到对话。

绑定使用用户明确确认的完整窗口标题。不要声称获得稳定聊天 ID；同名聊天不能区分，改名后需重新绑定。未绑定、未知或已停用角色不显示旧工牌。替换其他角色绑定前须有用户明确选择。

管理插件不直接占用宿主原生摘要栏。独立浮动、拖动、翻面和重启恢复由可选本地加载器承担，需要用户按完整包 INSTALL.md 显式登记、启动或启用登录项。仅管理工牌的请求不授权连接调试端口或操作其他应用；用户已明确授权某项本地安装或排障时，按该范围完成，不重复索要许可，不绕过宿主拒绝或安全策略。

卡片顶部可拖动，右上角可折叠、关闭。关闭后原位置的“显示工牌”可在当前已绑定聊天恢复；长期隐藏用停用或解除绑定。位置、翻面和折叠状态保存在本机，缓存有容量上限。

默认资料目录为 `~/Library/Application Support/MaiBadges`。升级保留资料；不要把删除数据库当作普通排障。工具返回的角色资料可能进入 MCP 宿主聊天，不能向用户保证宿主不保存这些资料。
