# 升级到 MaiBadges 0.8.0

完整步骤见 [根目录 UPGRADE.md](../../UPGRADE.md)。0.7.0 公开包只有右侧浮动工牌，0.8.0 补入左侧员工卡片与性能优化。必须更新完整源码或安装包，保持同一个资料目录，先停止加载器并备份，再运行 `prepare` 准备新版运行时，通过宿主正常功能更新同一来源的 `work-badges` 插件，最后重新启动加载器。

关闭旧管理页后重新调用 `work_badges_open`。保留原 state 目录即保留角色、头像和绑定，不需要重新上传或重建。不要通过清空资料库或编辑插件缓存刷新界面；`install-launcher` 只更新入口，不能代替完整升级。公开版没有私人定制版本的自动资料迁移。

验收左侧仅装饰明确绑定、可识别且无歧义的导航行，并保留点击与定时任务图标；未绑定或有歧义的行保持宿主原样。桌面适配依赖宿主版本与页面结构。
