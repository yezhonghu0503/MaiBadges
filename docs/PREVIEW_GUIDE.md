# 本地预览

在仓库根目录构建后，用回环 HTTP 服务打开公开示例：

```sh
python3 build_package.py
python3 -m http.server 8795 --bind 127.0.0.1 --directory plugins/work-badges/previews
```

构建会自动生成以下预览，在浏览器中访问：

| 地址 | 内容 |
| --- | --- |
| `http://127.0.0.1:8795/holo-badge-preview.html` | 共享浮动工牌渲染器 |
| `http://127.0.0.1:8795/manager-preview.html` | 只读管理页示例 |
| `http://127.0.0.1:8795/sidebar-preview.html` | 使用发布包侧栏实现的通用模拟导航 |

服务只监听本机；结束时在运行服务的终端按 Ctrl+C。

示例不读取真实资料库、不保存聊天绑定，也不包含私人图像。管理真实角色请安装本地插件并调用 `work_badges_open`。预览使用原创几何素材与虚构聊天行，是公开模拟导航验证，不能证明真实桌面宿主的页面结构、调试端口或登录自启已通过验收。

建议检查明暗主题、窄布局、头像回退、长职责、翻面、拖动、折叠、关闭恢复、缓存切回，以及系统“减少动态效果”。截图和录像应只使用公开示例，不录入私人聊天标题或个人头像。

侧栏预览提供以下检查控件：

- 切换 280 px／420 px 宽度，检查窄、宽导航布局。
- 移除和恢复装饰，确认原生导航行保留。
- 添加和移除同名聊天，观察歧义判断和安全跳过。
- 点击左侧示例行，核对原生点击计数仍更新；切换任务状态，核对定时任务图标和状态仍可见。
- 在输入区输入文字，或点击“模拟正文更新”运行 60 帧虚构正文变化，观察扫描计数，检查正文和输入变化不会触发无关导航扫描。

页面中的状态计数用于检查这份模拟导航中的行为，不是桌面宿主兼容性证明，也不代表真实聊天数据或统一的性能指标。
