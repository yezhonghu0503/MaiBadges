# MaiBadges 桌面入口

专属入口 `MaiBadges.app` 是用户自有的轻量启动器。它请求打开已安装的目标桌面应用，并附加本地调试参数；不包含官方应用、不修改其安装包、不替代其更新流程，也不强制退出已有进程。

首次准备与安装命令见 [INSTALL.md](../INSTALL.md)。默认入口位置为 `~/Applications/MaiBadges.app`，其软链指向用户状态目录中的启动器。在 Finder 按 Cmd+Shift+G，输入 `~/Applications` 即可找到，然后可自行拖入 Dock。搜索索引未更新时，以实际目录为准。

入口只在需要可选浮动加载器时使用。只使用管理插件不需要专属入口。已经运行的应用可能不接受追加调试参数；首次启用或端口不可用时，先自行保存工作、退出目标应用，再从专属入口打开。

启动器不会自动登记窗口；首次需运行 `enroll` 并选择主窗口，再显式 `start` 或 `enable-login`。登录自启恢复也要求目标应用调试会话可用。普通应用图标或软链无法替启动器附带参数。

重新运行 `install-launcher` 只处理名称、图标和入口，不更新管理页或运行时。升级见 [UPGRADE.md](../UPGRADE.md)。默认不需要管理员权限，不建议为此改动系统应用目录。

卸载时先停用登录项和加载器，再使用 `uninstall-launcher`、`remove-launchers`；只移除本项目拥有的入口，保留个人资料。调试会话仍运行时端口可能保持开启，关闭工牌不等于关闭端口。
