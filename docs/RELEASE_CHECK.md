# 0.8.0 发布检查

- 代码和原创几何示例采用 MIT；字体 OFL 与 Holo Card MIT 声明单独保留。
- 公开资源只包含代码生成的几何工牌、原创图标和有独立许可的字体，不包含个人品牌头像、团队人物、私有签名字体、聊天资料或生产制作记录。
- 0.7.0 公开包仅含右侧浮动工牌。0.8.0 的发布范围同时包含左侧已绑定员工卡片与性能优化，完整源码和安装包应保持一致。
- 左侧适配只装饰已确认绑定、可识别且无歧义的导航行；验收需覆盖未绑定、停用、重名、页面结构不支持时保持原样，以及原有点击和定时任务图标保留。
- 性能验收关注未变化资料不重复传输或渲染、会话缓存上限、头像更新后的缓存失效，以及导航扫描合并、正文变动不触发无关扫描、DOM 替换后的重新发现、隐藏或卸载时取消动画帧。不要把减少重复工作写成未经测量的耗时或内存降幅。
- 本次离线检查项目、测试数量、时间和结果以仓库根目录 `VALIDATION.json` 为准；0.7.0 的历史计数不能作为 0.8.0 已通过的证据。
- 构建自动生成 `plugins/work-badges/previews/sidebar-preview.html`，使用发布包的侧栏实现、原创几何素材与虚构导航行，不包含私人图像。通过 [本地预览流程](PREVIEW_GUIDE.md) 可检查 280 px／420 px 宽度、装饰恢复与移除、同名聊天、原生点击计数、定时任务状态切换，以及输入和 60 帧正文更新时的扫描计数。
- 侧栏预览属于公开模拟导航验证；控件可用或离线回归通过不能写成真实桌面宿主已通过验收。最终测试数量仍以本次 `VALIDATION.json` 为准，不在本文固定中途计数。
- `docs/demo.png` 是通用示例的共享工牌渲染器截图；该图不证明左侧适配已在所有桌面客户端运行。
- 可选 CDP 加载器仍属实验性社区适配。离线测试和浏览器预览不代表已通过真实桌面宿主安装验收；实际验收范围应按本次记录说明。
- 公开包使用白名单打包，MCP 入口保持 python3 与 ${PLUGIN_ROOT} 可移植配置。
- 升级说明保留 `work-badges` 身份与 `~/Library/Application Support/MaiBadges` 默认路径，要求完整源码或安装包更新、`prepare`、宿主正常插件更新和重新启动加载器；不把 `install-launcher` 写成完整升级。

GitHub Actions 的远程检查结果以仓库实际运行记录为准；本文件不把本地检查写成远程 CI 通过。
